**tools**

|  |  |
|---|---|
| <kbd>v</kbd> select · move · resize | <kbd>l</kbd> straight line |
| <kbd>r</kbd> rectangle | <kbd>p</kbd> pencil · freehand |
| <kbd>d</kbd> diamond | <kbd>t</kbd> text · double-click edit |
| <kbd>o</kbd> ellipse | <kbd>h</kbd> pan · middle-click drag |
| <kbd>a</kbd> arrow |  |

<br>

**select & transform**

|  |
|---|
| <kbd>ctrl</kbd> + click · toggle multi-select |
| drag empty space · marquee select |
| <kbd>alt</kbd> + drag · duplicate |
| <kbd>shift</kbd> + corner drag · aspect lock |
| drag top handle · rotate |

<br>

**actions**

|  |  |
|---|---|
| <kbd>ctrl+z</kbd> undo · <kbd>ctrl+shift+z</kbd> redo |
| <kbd>ctrl+c</kbd> / <kbd>ctrl+x</kbd> / <kbd>ctrl+v</kbd> copy · cut · paste |
| <kbd>ctrl+d</kbd> duplicate · <kbd>delete</kbd> delete |
| <kbd>ctrl+a</kbd> select all |
| <kbd>←</kbd> <kbd>↑</kbd> <kbd>→</kbd> <kbd>↓</kbd> nudge 1px · <kbd>shift</kbd> + arrow 10px |

<br>

**context menu** — right-click anywhere

```
flip horizontal / vertical
bring to front / forward / send backward / to back

align left / center / right / top / middle / bottom
distribute horizontally / vertically

copy / cut / paste / delete
copy style / paste style
copy to clipboard as png
```
